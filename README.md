# 🎮 VibeGuide

**VibeGuide** — это интерактивный веб-сайт-помощник для игроков Minecraft (специально для сервера **PlusVibe**). 

Здесь собраны 3D-схемы популярных ферм, лучшие комбинации чар и полезные гайды по выживанию.

## ✨ Основные фишки
*   **Интерактивные 3D-схемы:** Смотри, как устроены фермы железа и криперов прямо в браузере. Вращай камеру и летай на WASD!
*   **Список блоков:** Удобная панель, которая автоматически считает, сколько и каких блоков нужно для постройки.
*   **Гайды по чарам:** Актуальные сетапы для брони и оружия (версия 1.21).
*   **Стильный дизайн:** Тёмная тема с неоновыми акцентами, вдохновлённая сайтом сервера.

## 🛠 Технологии
Проект написан с использованием современных инструментов:
*   **Vite** — сборщик проекта.
*   **Three.js** — движок для 3D-графики.
*   **Lodestone** — библиотека для рендеринга схем Minecraft.
*   **Litematic Reader** — для чтения и подсчета блоков из схем.
*   **HTML / CSS / JavaScript** — без тяжелых фреймворков.
